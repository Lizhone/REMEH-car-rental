# REMEH – Vintage Car Rental Platform

## Project Overview

REMEH is a full-stack web application developed to provide a digital platform for exploring and renting vintage and classic automobiles. The application combines an elegant user interface with backend API integration and database management to deliver a streamlined car rental experience.

The platform enables users to browse available vehicles, explore detailed car specifications, manage their accounts, and proceed through the car booking workflow.

## Key Features

- **Vintage Car Catalogue:** Browse and explore a curated collection of classic automobiles.
- **Vehicle Details:** View individual vehicle information, images, specifications, and rental pricing.
- **User Authentication:** User registration and login with JWT-based authentication.
- **Booking Workflow:** Select a vehicle and proceed through the rental booking process.
- **Backend API Integration:** Connect frontend components with backend services through REST APIs.
- **Database Management:** Store and manage application data using Microsoft SQL Server.
- **Responsive User Interface:** Designed to provide an accessible browsing experience across desktop and mobile devices.

## Application Architecture

The application follows a frontend-backend architecture:

- **Frontend:** Angular handles the user interface, navigation, and application interactions.
- **Backend:** Flask manages API endpoints, business logic, and authentication.
- **Database:** SQL Server handles persistent storage and retrieval of application data.
- **Authentication:** JWT supports authenticated access to protected application resources.

The objective of REMEH is to demonstrate the development of a complete web application by integrating modern frontend technologies, backend services, database operations, and authentication into a practical car rental platform.
